# shampoore-android

Android-клиент для [shampoore-core](https://github.com/Esteviredzu/shampoore).

Приложение поднимает VPN-подключение к shampoore, импортирует конфигурацию `shampoore://` или конфиг, который поддерживает ядро. Go-ядро подключается как `shampoore.aar`.

## Что умеет

- Работать как Android VPN-клиент через TUN.
- Импортировать конфигурацию `shampoore://` и конфиг из файла или URL, если это поддерживает ядро.
- Показывать состояние подключения и статистику из ядра.
- Фильтровать трафик по GeoIP. На клиенте включённые GeoIP-правила пускают трафик в обход туннеля. Список IP можно загрузить по ссылке: ```https://github.com/ipverse/country-ip-blocks/blob/master/country/ru/ipv4-aggregated.txt```.
- Фильтровать конкретные приложения: выбирать, какие приложения идут через туннель, а какие в обход.
- Подключать готовый список приложений для фильтра. Готовая ссылка для популярных российских приложений: ```https://github.com/Esteviredzu/russian_apps_android/blob/main/russian_apps.txt```.

## Как работает

Приложение запускает Go-ядро из `shampoore.aar` и передаёт ему файловый дескриптор TUN. Ядро отвечает за транспорты, мультиплексор, шифрование и соединение с выходной нодой. Приложение управляет VPN-сервисом.

## Быстрый старт

1. Откройте проект в Android Studio.
2. Дождитесь Gradle Sync. При первой синхронизации скачается `shampoore.aar` из релизов `shampoore-core` и закэшируется в `app/build/shampoore-core/`.
3. Подключите устройство или запустите эмулятор.
4. Нажмите Run.

## Локальный AAR

Если нужен свой `shampoore.aar`, соберите его в `shampoore-core` и положите в `app/libs/shampoore.aar`. Gradle возьмёт локальный файл и не будет скачивать AAR. Чтобы вернуться к скачиванию, удалите `app/libs/shampoore.aar`.
